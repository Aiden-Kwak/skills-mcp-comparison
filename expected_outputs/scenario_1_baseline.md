# 시나리오 1 — Baseline (도구 없음)

**프롬프트**: 지난 7일간 들어온 버그를 트리아지해서 가장 시급한 5개와 처리 권고안을 작성해줘.

## AI 응답 (예시)

죄송합니다. 현재 환경에서는 다음과 같은 제약이 있습니다:

- 사내 버그 트래커(Jira/Linear/GitHub Issues 등)에 접근할 도구가 연결되어 있지 않습니다
- 따라서 "지난 7일간 들어온 버그"의 실제 목록을 조회할 수 없습니다

대신 일반적인 버그 트리아지 방법론을 안내해 드립니다:

1. severity와 impact를 분리해서 평가
2. 영향받는 사용자 수와 대안 회피 방법 유무 확인
3. P0/P1/P2 정도로 단순화

실제 트리아지를 진행하시려면 사용 중인 버그 트래커를 알려주시거나, 버그 목록을 텍스트로 복사해 주시면 분석을 도와드릴 수 있습니다.

---

**핵심**: AI는 *아무것도 못한다*. 사용자가 직접 데이터를 복붙해 와야 함.
