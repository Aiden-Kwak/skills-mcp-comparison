## 🔥 즉시 처리 Top 5

### 1. [#1] 결제 처리 500 에러 - 카드 청구는 됐으나 주문 미생성
- **점수**: 67.5 (impact 5 × urgency 3 × scope 3 × enterprise ×1.5)
- **사유**: 자금 영향 $47K/24h, Enterprise 3사, 데이터 일관성 깨짐
- **권고**: 즉시 에스컬레이션 → 결제팀 온콜 페이지
- **임시 조치**: Stripe webhook 일시 차단 후 수동 정산. charge.succeeded 이벤트 별도 큐로 우회 처리

### 2. 🚨 [#5] CSV export 시 다른 사용자 행이 1~2개 섞임
- **재평가 severity**: medium → **critical**
- **점수**: 45 (impact 5 × urgency 3 × scope 2 × enterprise ×1.5)
- **사유**: 데이터 격리 위반 — 멀티테넌시 보안 침해. GDPR 영향 가능. 신고자가 medium으로 잡았으나 description의 "다른 워크스페이스의 row 포함"은 cross-tenant data leak.
- **권고**: 즉시 에스컬레이션 → 보안팀 + 데이터팀
- **임시 조치**: 10K rows 초과 export 비활성화. 영향받은 export 로그 감사. 영향 고객 통지 검토.

### 3. 🚨 [#4] 관리자 페이지에서 다른 워크스페이스 데이터가 잠깐 보임
- **재평가 severity**: medium → **critical**
- **점수**: 36 (impact 5 × urgency 3 × scope 2 × ×1.2 자체 발견)
- **사유**: "UI 깜박임" 으로 보고됐으나 실제로는 **캐시 키 격리 실패**. 1초든 1ms든 다른 회사 데이터 노출은 동일 위반.
- **권고**: 즉시 에스컬레이션 → 인프라팀
- **임시 조치**: 관리자 페이지 캐시 비활성화 또는 워크스페이스 ID를 캐시 키에 강제 포함

### 4. 🚨 [#3] 비밀번호 재설정 링크가 만료 후에도 작동
- **재평가 severity**: low → **critical**
- **점수**: 30 (impact 5 × urgency 3 × scope 2)
- **사유**: 인증 우회. 토큰 만료 검증 실패로 만료된 링크가 1회 사용 가능. low로 분류된 이유는 신고자가 "1회만"이라고 봤기 때문이나, 1회로도 계정 탈취 가능.
- **권고**: 보안팀 핫픽스
- **임시 조치**: 모든 활성 reset 토큰 강제 만료. 토큰 검증 로직에 expiry 체크 강화.

### 5. [#2] Production DB 응답 시간 30초 이상 - 일부 쿼리 timeout
- **점수**: 27 (impact 4 × urgency 3 × scope 3 × oncall ×1.3 × 0.6 이미 in_progress)
- **사유**: 자동 모니터링 알람으로 객관적 증상. /api/dashboard 전체 영향. 이미 처리 중이므로 신규 액션보다 진행 추적.
- **권고**: 진행 상황 1시간 단위 보고 요청. ETA 명시 요구.
